# Gabriele Prato

Personal research website: https://gabprato.github.io/

A static, responsive page with automatic light and dark themes. No build step or dependencies are required. GitHub Pages publishes from the root of `master`.

## Edit

- Bio and links: `index.html`
- Layout and colors: `styles.css`
- Résumé: `assets/gabriele-prato-resume.pdf`
- Portrait: `assets/portrait.jpeg`

To preview, open `index.html` in a browser or run `python3 -m http.server 8000` in this directory and visit http://localhost:8000.
